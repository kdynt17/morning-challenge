# 2-5 아침 챌린지

2학년 5반 학급 페이지입니다. 학생들은 매일 출석 체크를 하고, 두뇌 트레이닝 게임(지뢰찾기·계산 20·색깔 판단·순간 기억)으로 포인트를 모은 뒤 상점에서 상품을 삽니다.

- 정적 사이트(GitHub Pages) + Firebase Authentication + Realtime Database
- `index.html` / `app.js` / `styles.css`: 학생·선생님 화면
- `minesweeper.js`: 지뢰찾기 게임 엔진 (Firebase와 무관)
- `games/`: 두뇌 트레이닝 게임 (`calc20.js`, `stroop.js`, `memory.js`)
- `brain.js`: 두뇌 지수(BQ)·영역 점수·등급·레벨 계산
- `manifest.webmanifest`, `icons/`: 홈 화면에 추가했을 때 앱 아이콘
- `developer/`: 가입 승인 페이지 (선생님 전용)
- `database.rules.json`: DB 보안 규칙

## 포인트 설계

목표: 꾸준히 하는 학생이 **약 6~8주에 2,000P**를 모으도록.

| 방법 | 포인트 |
|---|---|
| 출석 체크 | 하루 1번 +10P |
| 7일 연속 출석 | 보너스 +30P (7, 14, 21일째…) |
| 지뢰찾기 성공 | 초급 +5P · 중급 +12P · 고급 +30P |
| 계산 20 · 색깔 판단 · 순간 기억 | 끝까지 하면 +5P (계산·색깔은 10문제 이상 정답, 기억은 3개 이상 성공) |
| 게임 포인트 상한 | 하루 최대 30P (상한 이후에도 기록은 저장) |
| 월말 순위 보상 | 난이도별 TOP 3 — 고급 100·60·40P, 중급 60·40·20P, 초급 30·20·10P |

- 매일 출석 + 게임 상한까지: 하루 약 44P → 약 6~7주
- 출석 + 중급 1판: 하루 약 26P → 약 2달 반
- 값은 `app.js` 맨 위 상수(`POINT_GOAL`, `GAME_RULES` 등)에서 바꿀 수 있습니다. 게임 상한(30P)과 최소 기록 시간은 `database.rules.json`에도 있으니 같이 바꿔야 합니다.

## 지뢰찾기

- 초급 9×9(지뢰 10) · 중급 16×16(40) · 고급 16×30(99). 폰에서는 고급 판을 세로(30×16)로 돌립니다.
- 첫 칸과 그 주변은 항상 안전합니다. 깃발: PC 오른쪽 클릭, 폰 길게 누르기 또는 깃발 모드.
- 처음 게임 화면에 들어오면 설명서 팝업이 뜨고, "다시 보지 않기"는 그 기기(브라우저)에 저장됩니다. 내 정보에서 다시 볼 수 있습니다.
- 순위: 이번 달 난이도별 최단 기록(`msRecords/{YYYY-MM}/{난이도}`). 비정상적으로 빠른 기록(초급 2초, 중급 8초, 고급 25초 미만)은 규칙에서 거부합니다.
- 월말 보상은 선생님 관리 화면 → "월말 지뢰찾기 순위 보상"에서 미리보기 후 지급합니다. 한 달에 한 번만 지급됩니다.

## 두뇌 트레이닝과 두뇌 지수

| 게임 | 영역 | 기록 | 영역 점수 100점 / 0점 기준 |
|---|---|---|---|
| 계산 20 | 계산력 | 20문제 시간 + 틀린 문제당 5초 | 20초 / 110초 |
| 색깔 판단 | 집중력 | 20문제 시간 + 틀린 문제당 3초 | 18초 / 60초 |
| 순간 기억 | 기억력 | 기억한 최대 숫자 개수 | 12개 / 2개 |
| 지뢰찾기 | 추리력 | 성공 시간 | 초급 8초(최대 70점), 중급 35초(최대 90점), 고급 110초 |

- 영역 점수 = 그 영역 최근 10판 중 잘한 3판의 평균. 한 번 운 좋게 잘한 기록보다 지금 실력을 보여줍니다.
- 두뇌 지수(BQ) = 70 + 네 영역 평균 × 0.85 (70~155). 네 영역을 모두 한 번 이상 해야 나옵니다.
- 등급: 워밍업(~84) · 스파크(85~) · 브레인(100~) · 에이스(115~) · 마스터(130~) · 레전드(145~)
- 레벨(Lv)은 실력과 별개로 플레이한 만큼 오릅니다(XP: 두뇌 게임 10, 지뢰찾기 성공 10/20/40, 실패 2).
- 기준값은 `brain.js`에서 바꿀 수 있습니다.

## 자동 로그인

- 로그인 정보는 브라우저(IndexedDB)에 저장돼서, 다시 열면 로딩 화면 뒤에 바로 들어갑니다. 공용 컴퓨터에서는 "로그인 상태 유지"를 끄면 창을 닫을 때 로그아웃됩니다.
- 마지막 로그인 이메일은 그 기기에 기억돼서 로그인 칸에 미리 채워집니다.
- 카카오톡 안에서 열거나 시크릿 창이면 브라우저가 로그인 정보를 지웁니다. 홈 화면에 추가해서 쓰는 것을 권장합니다.

## 가입 승인

- 새로 가입한 학생은 `status: "pending"`으로 시작하며, 선생님이 승인하기 전까지 대기 화면만 보입니다.
- 선생님은 `developer/` 페이지(관리 화면의 "가입자 승인 · 관리 페이지 열기")에서 승인·거절·승인 취소를 합니다.
- 승인 기능 이전에 가입한 학생은 `status`가 없으며 승인된 것으로 처리됩니다.

## 비밀번호 재설정

로그인 화면의 "비밀번호를 잊었어요"를 누르면 입력한 이메일로 Firebase 재설정 메일이 발송됩니다.
메일 문구는 Firebase Console → Authentication → 템플릿에서 바꿀 수 있습니다.

## 데이터베이스 규칙 게시

`database.rules.json`을 바꾼 뒤에는 Firebase Console → Realtime Database → 규칙 탭에 내용을 붙여넣고 게시해야 적용됩니다.

## 알려진 한계

채점·포인트 지급이 학생 브라우저에서 일어나므로, 승인된 학생은 개발자 도구로 자기 포인트를 바꿀 수 있습니다.
완전히 막으려면 포인트 지급을 Cloud Functions(서버)로 옮겨야 합니다.

## 디자인 이미지

이미지를 못 불러오면 자동으로 숨겨지고 나머지 화면은 그대로 동작합니다.
