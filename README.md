# 2-5 아침 챌린지

정식 주소: https://kdynt17.github.io/morning-challenge/
Firebase 프로젝트: morning-quest (Spark). 다른 저장소의 규칙을 배포하지 마세요.

학생용 규칙은 [문제·포인트 규칙](rules.html)을 참고하세요.

- 시험 대비로 두뇌교실 게임을 모두 내렸습니다(나중에 다시 만들 예정). 과거 게임 기록(academy/, records/)은 지우지 않고 쓰기만 막았습니다.
- **오늘의 문제 (처음 버전 방식)**: 선생님이 관리 화면에서 날짜별로 하루 한 문제(제목·내용·사진·정답)를 올립니다. 학생은 문제 화면에서 답을 적어 제출하고, 먼저 맞힌 순서대로 1등 150점부터 5점씩 줄어든 점수를 받습니다. 틀리면 10점 감점 후 다시 제출(하루 최대 10번). 디자인은 2026-11-15에 현대적인 앱 스타일(미색 바탕·검정 잉크·라임 포인트, Pretendard 한 글꼴)로 다시 다듬었습니다.
- 채점은 DB 규칙이 합니다. 정답은 `quiz/answers`(선생님만 읽기)에 키 모양(quiz.mjs `answerKey`)으로 저장되고, 학생이 `quiz/correct`에 맞혔다고 쓰면 규칙이 정답과 비교해 거절하거나 받아 줍니다. 맞힌 시각은 서버 시각입니다.
- 선생님은 '문제 기록'에서 날짜별로 마감·다시 받기·정답 공개·삭제를 하고, 정답 순서와 틀린 학생의 마지막 답을 봅니다. '문제 풀이 잠금'(예전 게임 잠금 자리 settings/gamesLocked)을 켜면 답을 낼 수 없습니다.
- **신고**: 학생 메뉴 '신고'에서 ① 침입 알림(누르면 선생님 화면에 소리·알림, ntfy 알림 주소가 있으면 휴대폰에 "신고가 들어왔어요"만 보냄) ② 욕설·괴롭힘 신고(1~28번 항목 버튼, 관련 학생 이름 자동완성, 언제·누가·누구에게·뭐라고). 신고는 `reports`에 저장되고 선생님만 읽습니다. 관리 화면에서 항목 이름(settings/reportCategories), 처리 완료, 이름이 나온 학생 집계를 봅니다.
- 출석(월~금 자동 10P, 7일 연속 +30P), 포인트 순위, 상점, 가입 승인, 선생님 포인트 지급·차감은 그대로입니다.
- 로그인: 기본은 예전처럼 학번(또는 이메일)·비밀번호. 이미 로그인돼 있는 학생은 그대로 들어옵니다. **들어오지 못하는 학생만** 학교 구글 계정(@junghwa.sen.ms.kr)으로 로그인하고, 선생님이 예전 기록과 연결합니다. 다른 구글 계정은 로그인 직후 막고 지우며, DB 규칙도 새 가입을 인증된 학교 이메일로만 받습니다.
- 학급 내부 신뢰를 전제로 하는 클라이언트 포인트 지급 방식입니다(채점은 규칙이 하지만, 포인트 반영은 학생 기기에서 합니다).

## 구글 로그인으로 옮기기 (기록 그대로)

기록은 계정 번호(uid)에 묶여 있으므로, 데이터를 옮기지 않고 **예전 계정에 구글 로그인을 붙입니다**. Firebase의 Google 로그인은 켜 두었습니다(무료).

1. 로그인돼 있거나 비밀번호를 아는 학생은 그대로 씁니다(구글 연결 안 해도 됨).
2. 비밀번호를 잊어 못 들어오는 학생: **학교 구글 계정으로 로그인**을 누릅니다.
   - Firebase가 같은 이메일의 예전 계정에 바로 합쳐 주면 그대로 들어갑니다.
   - "예전 계정이 아직 구글과 연결되지 않았어요"가 나오면, 선생님이 `developer/` 전체 가입자에서 그 학생의 **구글 로그인 열기**를 누르고, 학생이 다시 로그인합니다.
   - 새 구글 로그인은 `developer/`의 **구글 로그인 연결**에 나옵니다. 예전 계정(이메일·학번·이름으로 자동 추천)을 확인하고 **기존 기록과 연결**을 누르면, 학생은 **다시 구글로 로그인**으로 원래 계정에 들어갑니다. 이메일이 같은 학생은 한 번에 연결할 수 있습니다.
3. 연결·열기·비밀번호 재설정은 처음 한 번 Firebase 프로젝트 주인 구글 계정의 허락(토큰, 약 1시간)을 받아 Identity Toolkit API를 부릅니다. '확인되지 않은 앱' 경고가 나오면 '고급 → 이동'.

구글 연결 전 학생의 비밀번호는 `developer/`의 **비밀번호 재설정**으로 바꿀 수 있습니다. 예비 방법: `GOOGLE_APPLICATION_CREDENTIALS=키.json node tools/reset-password.mjs 202620501 새비밀번호`.
