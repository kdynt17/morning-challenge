# 2-5 아침 챌린지

정식 주소: https://kdynt17.github.io/morning-challenge/
Firebase 프로젝트: morning-quest (Spark). 다른 저장소의 규칙을 배포하지 마세요.

학생용 최신 규칙은 [게임·포인트 규칙](rules.html)을 참고하세요.

- 5영역 두뇌교실에 60초형 13게임 + 기존 추가 연습 3게임을 모았습니다.
- 색깔판단은 직감·주의력, 순간기억 단계 도전은 기억, 계산20은 계산 영역입니다.
- 지뢰찾기 UI·실행 코드·월말 보상을 제거했습니다. 과거 DB 기록은 삭제하지 않고 쓰기만 차단했습니다.
- 매일 도전은 60초형 13게임 중 5영역 각 하나입니다. 기존 3게임은 원래의 20문제/단계 도전 방식을 유지합니다.
- 출석10P/7일연속30P, 도전완료50P(06시마감후 두뇌교실접속), 연습 영역당10P·하루50P. 세 추가 게임도 같은 영역의 지급 마스크를 공유합니다. 별도30P 보상은 폐지합니다.
- 모든 잔액은 원래 users/uid/points와 leaderboardUsers를 사용합니다. 신규 게임 기록은 academy 경로이며 기존 records의 월별 추가 연습 기록도 유지합니다.
- 말랑그램은 영역별 최근7회 평균입니다. 추가게임의 0~100 영역점수를 해당 영역 기준점수로 환산해 포함합니다. 실제 IQ가 아닙니다.
- 새 가입 승인, 자동로그인, 출석, 상점, 선생님 직접지급은 유지합니다.
- 학급 내부 신뢰를 전제로 하는 클라이언트 채점·보상 방식입니다. 승인된 학생의 개발자도구 조작까지 막는 서버 시스템은 아닙니다.
