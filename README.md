# 2-5 아침 챌린지

정식 주소: https://kdynt17.github.io/morning-challenge/
Firebase 프로젝트: morning-quest (Spark). 다른 저장소의 규칙을 배포하지 마세요.

학생용 규칙은 [문제·포인트 규칙](rules.html)을 참고하세요.

- 시험 대비로 두뇌교실 게임을 모두 내렸습니다(나중에 다시 만들 예정). 과거 게임 기록(academy/, records/)은 지우지 않고 쓰기만 막았습니다.
- **오늘의 문제**: 선생님이 관리 화면에서 문제(객관식·주관식, 사진 가능)를 올리고 정답을 고릅니다. 학생은 문제 메뉴에서 답을 내고, 먼저 맞힌 순서대로 1등 100P(문제마다 바꿀 수 있음)부터 한 등수마다 5P씩, 최소 1등의 20%를 받습니다. 객관식 기회 1번, 주관식 기본 3번.
- 채점은 DB 규칙이 합니다. 정답은 `quiz/answers`(선생님만 읽기)에 키 모양(quiz.mjs `answerKey`)으로 저장되고, 학생이 `quiz/correct`에 맞혔다고 쓰면 규칙이 정답과 비교해 거절하거나 받아 줍니다. 맞힌 시각은 서버 시각입니다.
- 선생님은 문제마다 공개·마감·다시 받기·정답 공개·삭제를 할 수 있고, 맞힌 순서와 틀린 학생의 마지막 답을 봅니다. '문제 풀이 잠금'(예전 게임 잠금 자리 settings/gamesLocked)을 켜면 답을 낼 수 없습니다.
- 출석(월~금 자동 10P, 7일 연속 +30P), 포인트 순위, 상점, 가입 승인, 선생님 포인트 지급·차감은 그대로입니다.
- 로그인: 학번만 적으면 `학번@junghwa.sen.ms.kr`로 로그인합니다.
- 학급 내부 신뢰를 전제로 하는 클라이언트 포인트 지급 방식입니다(채점은 규칙이 하지만, 포인트 반영은 학생 기기에서 합니다).

## 학생 비밀번호 재설정

`developer/`(가입자 관리)에서 학생 줄의 **비밀번호 재설정**을 누르고 새 비밀번호를 두 번 적습니다. 지금 비밀번호는 볼 수 없습니다.
처음 한 번만 아래 설정이 필요합니다.

1. Firebase 콘솔 → Authentication → 로그인 방법 → **Google** 사용 설정(지원 이메일 선택).
2. Authentication → 설정 → 승인된 도메인에 `kdynt17.github.io`가 있는지 확인.
3. 재설정 버튼을 누르면 뜨는 구글 창에서 **Firebase 프로젝트 주인 구글 계정**을 고릅니다. '확인되지 않은 앱' 경고가 나오면 '고급 → 이동'을 누르고 'Google Cloud 데이터 보기·관리' 권한을 허락합니다. 토큰은 1시간 정도 기억하고 저장하지 않습니다.

예비 방법: 서비스 계정 키(JSON)가 있으면 `GOOGLE_APPLICATION_CREDENTIALS=키.json node tools/reset-password.mjs 202620501 새비밀번호`.
